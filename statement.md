# Project Statement & System Scope

## Problem Statement
University placement cells manage thousands of student resumes across rapidly changing recruitment criteria from multiple visiting companies. Manual evaluation leads to screening delays, human error in tracking CGPA cutoffs and active backlogs, and difficulty in managing multi-round candidate interview statuses.

## Target Users
- **Placement Officers:** Administer eligibility rules, track candidate progress, and monitor overall placement analytics.
- **Corporate Recruiters:** Define job requirements and filter applicant pools instantly.
- **Student Applicants:** Track round progress and receive official offer documentation.

## Scope of Project
The system provides automated eligibility screening using functional predicate logic, multi-stage interview tracking, real-time analytics calculations, and offer document generation.

## High-Level System Features
1. **Dynamic Rule-Based Screening:** Java 8 Stream API evaluation against CGPA, active backlogs, department matching, and skill tags.
2. **Multi-Round Interview Tracker:** Operational advancement from Aptitude Cleared → Technical Cleared → Placed.
3. **Analytics Dashboard:** Metrics calculation for total applicants, placed ratio, and average CTC offerings.
4. **Offer Document Generator:** Automated employment offer letter creation for placed candidates.
